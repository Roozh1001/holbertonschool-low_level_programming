# C - Function pointers

This project explores function pointers in C.

## Tasks

### 0. What's my name
- File: `0-print_name.c`
- Prototype: `void print_name(char *name, void (*f)(char *));`
- Description: calls the function pointed to by `f` with `name` as its argument.

## Compilation

    gcc -Wall -pedantic -Werror -Wextra -std=gnu89 *.c -o function_pointers
