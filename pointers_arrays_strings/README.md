# C - Pointers, arrays and strings

This project introduces pointers, arrays and strings in C.

## Description

Each file contains a function that practices working with pointers
(for example, changing a value through its address).

## Requirements

- Compiled on Ubuntu 20.04 LTS with `gcc -Wall -Werror -Wextra -pedantic -std=gnu89`
- Code follows the Betty style
- No global variables
- No standard library functions (only `_putchar` is allowed)

## Files

| File | Description |
|------|-------------|
| `main.h` | Header file with the function prototypes |
| `0-reset_to_98.c` | Function that updates the value pointed to by an `int *` to 98 |
