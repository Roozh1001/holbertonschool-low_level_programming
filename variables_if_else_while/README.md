# C - Variables, if, else, while

This project covers variables, `if`/`else` statements, and `while` loops in C.

## Tasks

* `0-positive_or_negative.c`: prints whether a random number is positive, zero, or negative.

## Requirements

* Compiled on Ubuntu 20.04 LTS with `gcc -Wall -Werror -Wextra -pedantic -std=gnu89`
* Code follows the Betty style
